# ControlPanel — 비정상 상태 컨트롤 패널

Mac에서 실행합니다. 시작을 누른 순간의 실측값으로 MATLAB 디지털 트윈을 초기화해 고장을 재현하고, 결과를 Pi를 거쳐 AE와 MCU로 보냅니다.

## 실행

```bash
bash "../AI_AutoEncoder(RaspberryPi)/RaspberryPi/monitor/run.sh"   # 먼저 모니터
zsh run.sh                                          # 패널 → http://127.0.0.1:8060 (처음에는 MATLAB 준비에 약 1 분)
zsh stop.sh                                         # 종료
```

Mac과 Pi가 USB(`10.55.0.2`)로 연결되어 있어야 합니다. MATLAB R2025b에서 실행했습니다.

**팀 Simulink 모델은 이 저장소에 없습니다.** 처음에 `sim_worker.m` 맨 위의 `WORK_DIR`에 모델 폴더(`AI_BMS_4S.slx`, `aibms_parameters.m`, `aibms_scenario.m`) 경로를 넣어 주세요. 비어 있으면 워커가 안내 문구를 내고 멈춥니다. `start.sh`, `stop.sh`의 Pi 계정도 환경에 맞게 바꿔 주세요.

## 시나리오

길이 20초, 5초에 고장이 시작됩니다. 값은 모두 MATLAB 모델의 결과이며 강제 판정을 쓰지 않습니다. 모델 BMS는 끄고, 판정과 차단은 실제 MCU가 합니다.

| 시나리오 | 시작 전 (모니터에서) | 고장 | AE 경보 | MCU 폴트 |
|---|---|---|---|---|
| Soft ISC 주행 | 모터 ON | 선택한 셀의 누설이 20초에 걸쳐 0.05 Ω까지 진행 | 6~7초 | 13~15초, CUV |
| Soft ISC 휴지 | 정상주행 시작 후 모터 OFF | 위와 같음 | **1초 (고장 전 경보, 아래 한계 참고)** | 13~15초, CUV |
| Soft ISC 충전 | 충전 ON | 위와 같음 | 약 6초 | 14~19초, CUV |
| 과충전 | 충전 ON | 충전기 전압 제어·전류 제한 상실 | 약 6초 | 13~15초, COV |

시간은 제공 가중치로 낸 Mac 평가 값이고, MCU 판정은 펌웨어와 같은 기준으로 계산했습니다. 실제 MCU 경로는 아직 확인하지 않았습니다.

폴트가 나면 실제 모터나 충전이 꺼집니다. **중지**를 누르면 폴트가 풀리고 모니터가 정상 모드로 돌아오지만, 출력은 자동으로 켜지지 않습니다.

## 동작

1. Pi에서 최근 실측 10표본 평균을 읽고, 전류로 시작 조건을 확인합니다.
2. MATLAB이 전압·전류로 초기 SOC를, 온도로 초기 온도를 잡아 계산합니다.
3. `x_out = x_sim + (x_실측 − x_sim 첫 1초 평균) + 센서 잡음`으로 실측에 맞춥니다.
4. 10 Hz로 Pi에 보냅니다. 시작 후에는 실측을 따라가지 않습니다.

## 과충전 재현 방식

- 15초 안에 일반 충전 속도로 4.25 V까지 갈 수 없어 약 4~8 A의 충전기 고장을 가정합니다.
- 전류는 추정값으로 한 번 돌린 뒤, 16초에 최고 셀이 4.256 V가 되도록 다시 맞춰 돌립니다.
- 충전기 파라미터를 시뮬레이션 중간에 바꿀 수 없어 정상 시뮬레이션 5초와 고장 시뮬레이션을 잇습니다.
- AE 경보에 "최고 셀 4.205 V 초과" 규칙이 함께 작동하는 경우가 많습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `run.sh` · `start.sh` · `stop.sh` | 실행, 시작 절차 (Pi 대리인 배포 포함), 종료 |
| `panel_server.py` · `panel.html` | Mac 서버, 화면, 세션 진행 |
| `sim_worker.m` | MATLAB 상주 워커. 팀 모델 파일은 고치지 않고 파라미터만 넘깁니다 |
| `frames.py` | 실측 맞춤, 센서 잡음, 고장 구간 잇기 |

## 알려진 한계

- Soft ISC 휴지 시나리오에서 AE가 고장 시작(5초) 전인 1초부터 경보를 냅니다. 휴지 전문가의 판정 경계가 좁기 때문으로 보이며, 휴지 데이터를 더 모아야 합니다.
- 패널은 최고 셀 4.08 V 이상의 충전에서 경고합니다. 이전 모델 기준이라 지금 모델에서는 필요 없을 수 있습니다.
- 고장이 심해지면 AE가 지목하는 셀이 바뀔 수 있습니다.
